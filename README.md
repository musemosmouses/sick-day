# The Funniest Sick-Day Excuse

Entry for make.fun bounty `u-zeroxfive-the-funniest-sick-day-excuse-37423a36`.

`main.ts` writes a single line — the funniest sick-day excuse, under 200
characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written,
no network, no randomness: the output is deterministic.
